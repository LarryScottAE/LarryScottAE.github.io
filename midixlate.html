True MIDI routing, not just a hub

Frequently Asked Questions

Everything you need to know about MidiXLate and MIDI routing.

What is a MIDI router?
A MIDI router is a hardware device that directs MIDI data from one or more input devices to one or more output devices. Unlike a simple MIDI thru box or hub that sends all data everywhere, a true MIDI router like MidiXLate inspects each MIDI packet and routes it only to the intended destination — giving you precise control over which devices receive which MIDI messages.
How is MidiXLate different from a MIDI hub or thru box?
A MIDI hub or thru box simply duplicates all incoming MIDI data and sends it to every connected device. MidiXLate is a true router — it inspects every MIDI packet and routes it exactly where you define, with filtering, translation, and channel locking. You control which input ports send to which output ports, and which types of MIDI messages are allowed through.
Can MidiXLate filter specific MIDI messages?
Yes. MidiXLate can filter by MIDI message type (Note, Program Change, Control Change, SysEx) on a per-port basis. For example, you can allow notes to pass from a keyboard to a synth while blocking program change messages, or limit a pedal board to only sending CC messages to specific devices.
How do I configure MidiXLate?
MidiXLate includes a free Windows PC configuration app. Connect via USB-C Port 2 and use the visual rule builder to define your routing, filtering, translation, and channel locking rules. Once configured, download the rules to the router — it then operates standalone without a PC connection.
Can I try MidiXLate before buying?

What is the latency of MidiXLate?
MidiXLate uses an 84 MHz ARM Cortex-M3 processor that handles each MIDI message in microseconds, resulting in less than 1ms of latency — far below any perceptible threshold for live performance.
Does MidiXLate work with all MIDI devices?
Yes. MidiXLate uses standard 5-pin DIN MIDI connections and is compatible with any device that sends or receives standard MIDI. It also has a USB-C port for connection to a PC running the configuration app or for use as a USB MIDI interface.
